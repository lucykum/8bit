# GreenLight AI 🟢

화장품 마케팅 문구의 법적 준수 여부를 자동으로 분석하고, 합법적인 대체 카피를 생성해주는 AI 컴플라이언스 서비스입니다.

---

## 주요 기능

- **위험도 분석** — 입력한 마케팅 문구의 법적 위험 등급(상/중/하) 및 예상 처벌 수위 제공
- **위반 키워드 탐지** — 금지 표현을 단어·구문 단위로 분리하고 합법적 대체 표현 추천
- **완성 카피 생성** — 썸네일 제목 3안, 본문 카피, 해시태그를 포함한 규정 준수 마케팅 문구 자동 생성

---

## 기술 스택

| 영역 | 기술 |
|------|------|
| Backend | FastAPI, Uvicorn |
| AI 모델 | Upstage Solar Pro 3 |
| 지식 베이스 | 화장품법, 화장품 표시·광고 관리 지침 (JSON 구조화) |
| 언어 | Python 3.10+ |

## 시작하기

### 1. 환경 변수 설정

`.env` 파일을 생성하고 Upstage API 키를 입력합니다.

```env
UPSTAGE_API_KEY=your_api_key_here
```

### 2. 의존성 설치

```bash
pip install -r requirements.txt
```

### 3. 서버 실행

```bash
uvicorn main:app --reload
```

서버가 실행되면 `http://localhost:8000` 에서 접근 가능합니다.

## API

